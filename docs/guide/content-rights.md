# 资料版权与下架

本网站收录协会整理、成员创作及公开渠道获得的学习资料。资料页面提供阅读和下载，不代表原作者、发布机构放弃其署名权、版权或其他权利，也不表示所有资料采用相同的开放许可。

部分历史资料的来源与再分发依据仍在逐项核验。引用或继续传播资料前，请优先查看原文件中的版权声明，并遵守原作者或发布机构规定的许可条件。

## 内容下架

如果你是相关权利人，或发现资料包含未经授权的内容、个人隐私或其他不适合公开的信息，请通过[内容下架申请](https://github.com/Zhr-ARM/free-knowledge-base/issues/new/choose)联系我们，并提供资料名称、页面地址和便于核实的说明。

核实后，我们会停止发布相关资料并处理已有页面。
