# 查找资料

知识库按技术方向展示资料。你可以从导航栏进入 [资料库](/library/)，也可以直接打开对应栏目。

## 按分类浏览

- [嵌入式](/guide/embedded)：适合查找 C 语言、STM32、ESP32、Arduino、传感器、通信协议和外设驱动资料。
- [机器人运动控制](/guide/robot-motion-control)：适合查找 ROS、机器人底盘、运动学、导航、SLAM、仿真和控制资料。
- [工具资源](/guide/resources)：适合查找常用软件、调试工具和参考链接。

## 使用搜索

页面顶部有搜索框。输入关键词后，可以快速定位标题和正文中包含相关内容的资料。

推荐关键词示例：

- `C语言`
- `STM32`
- `GPIO`
- `ROS2`
- `运动控制`
- `SLAM`

## 资料状态

如果某个分类还没有资料，页面会显示“暂无资料”。这表示当前知识库还没有公开收录对应内容。
