# 嵌入式资料导览

本区资料来自协会学习目录，经筛选后按主题公开。安装包、课程视频、编译缓存和重复文件没有收录。

## 目录

| 分类 | 主要内容 |
| --- | --- |
| 编程基础 | C 语言课程讲义、思维导图、示例源码 |
| 51 单片机 | STC89/STC15 练习、蓝桥杯开发板资料、芯片手册 |
| STM32 与实时系统 | FreeRTOS、RT-Thread、STM32F407 参考手册 |
| ESP32 | ESP-IDF 练习源码 |
| TI MSPM0 | MSPM0G3507 资料、原理图、练习源码 |
| 硬件设计与 PCB | 器件手册、参考原理图、PCB 设计工程 |
| Linux 与 Qt | Linux 入门与常用命令、Qt 示例源码 |
| 协会培训 | STM32 入门、蓝桥杯手册、竞赛特训资料 |

源码以 ZIP 文件提供。压缩包保留学习工程中的源码和配置，未包含工具链、编译产物与大型第三方依赖。
