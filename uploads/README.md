# 上传资料说明

把要展示在网站里的资料放在这个文件夹里。

推荐目录：

- `嵌入式/`：C 语言、STM32、ESP32、Arduino、传感器、外设驱动等资料
- `机器人运动控制/`：ROS、机器人建模、底盘控制、导航、仿真、SLAM 等资料

支持格式：

- `.md`：会转换为知识库页面
- `.pdf`：会生成网页预览页
- `.docx`：会尽量转换为网页内容，并保留原文件下载链接
- `.doc`：会生成下载页；建议转成 `.docx` 或 `.pdf` 后再上传

放入文件后，在项目根目录运行：

```bash
npm run sync:uploads
```

如果要发布到线上，再运行：

```bash
npm run docs:deploy
```
