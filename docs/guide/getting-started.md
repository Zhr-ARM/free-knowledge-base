# 开始使用

这里是开源协会的公开知识库，主要收录嵌入式和机器人运动控制相关资料。

## 推荐查找方式

1. 进入 [资料库](/library/) 查看全部资料。
2. 按“嵌入式”或“机器人运动控制”分类浏览。
3. 使用页面顶部搜索框查找关键词，例如 `C语言`、`STM32`、`ROS2`、`运动控制`。
4. 打开资料页后，可以在线阅读、预览 PDF，或下载原始文件。

## 当前收录方向

- 嵌入式：C 语言、单片机、传感器、通信协议、外设驱动和工程实践。
- 机器人运动控制：ROS、底盘控制、运动学、导航、SLAM、仿真和项目实践。

没有收录的主题会在资料库中显示“暂无资料”。
