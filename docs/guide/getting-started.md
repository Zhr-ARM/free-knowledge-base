# 开始使用

这里是开源协会的公开知识库，服务于电源、信号、控制（嵌入式）和控制（机器人）四个技术方向。

## 推荐查找方式

1. 进入 [资料库](/library/) 查看全部资料。
2. 按技术方向浏览，或直接搜索关键词。
3. 使用页面顶部搜索框查找关键词，例如 `C语言`、`STM32`、`FOC`、`运动控制`。
4. 打开资料页后，可以在线阅读、预览 PDF，或下载原始文件。

## 当前收录方向

- 电源：暂无资料。
- 信号：暂无资料。
- 控制（嵌入式）：C 语言、单片机、传感器、通信协议、外设驱动和工程实践。
- 控制（机器人）：学习路线、电机控制、FOC 和强化学习。

其他尚未收录的主题会明确显示“暂无资料”。
