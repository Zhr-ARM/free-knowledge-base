# 上传资料说明

把要展示在网站里的资料放在这个文件夹里。

推荐目录：

- `嵌入式/01-编程基础/`
- `嵌入式/02-51单片机/`
- `嵌入式/03-STM32与实时系统/`
- `嵌入式/04-ESP32/`
- `嵌入式/05-TI-MSPM0/`
- `嵌入式/06-硬件设计与PCB/`
- `嵌入式/07-Linux与Qt/`
- `嵌入式/08-协会培训/`
- `机器人运动控制/01-电机控制/`
- `机器人运动控制/02-强化学习/`

支持格式：

- `.md`：会转换为知识库页面
- `.pdf`：会生成网页预览页
- `.docx`：会尽量转换为网页内容，并保留原文件下载链接
- `.doc`：会生成下载页；建议转成 `.docx` 或 `.pdf` 后再上传
- `.zip`、`.rar`、`.7z`：会生成源码包或压缩包下载页
- `.xmind`、`.xls`、`.xlsx`、`.ppt`、`.pptx`：会生成原文件下载页

可以继续建立子文件夹。网站会按文件夹层级自动生成目录，文件名将作为资料标题。

放入文件后，在项目根目录运行：

```bash
npm run sync:uploads
```

如果要发布到线上，再运行：

```bash
npm run docs:deploy
```
