# 嵌入式

这里汇总协会已公开的嵌入式学习资料，并按学习方向整理。

## 当前目录

| 分类 | 已收录内容 |
| --- | --- |
| 编程基础 | C 语言讲义、思维导图与课程源码 |
| 51 单片机 | STC15/STC89 练习、蓝桥杯开发板资料与芯片手册 |
| STM32 与实时系统 | FreeRTOS、RT-Thread、STM32F407 参考资料 |
| ESP32 | ESP-IDF 练习源码 |
| TI MSPM0 | MSPM0G3507 资料、原理图与练习源码 |
| 硬件设计与 PCB | 常用器件手册、参考原理图与 Altium Designer 工程 |
| Linux 与 Qt | Linux 入门、常用命令与 Qt 示例 |
| 协会培训 | STM32、蓝桥杯和竞赛特训资料 |

## 查找入口

进入 [资料库](/library/) 后展开“嵌入式”下的目录，可在线预览文档或下载原始文件。也可以用顶部搜索框查找芯片型号、开发板名称或技术关键词。
